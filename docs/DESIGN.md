# 饭碗 IronBowl — 设计清单

> 2026-11-25 拷问确认版。改设计先改这里。

## 技术与形态

- SwiftUI 原生，仅 macOS 26；视觉风格参照 WorkBuddy（见下方「视觉规范」），跟随系统深浅色。
- 主窗口（侧边栏 + 插件页）+ 菜单栏图标。开机自启、是否占程序坞、菜单栏显示项（多选可排序）都在设置里。
- 数据：`~/Library/Application Support/IronBowl/ironbowl.sqlite`（GRDB，WAL）。禅道账号密码明文存库（用户决定）。独立版万年历共用此库。
- 工程：XcodeGen（`project.yml`），不提交 `.xcodeproj`。

## 视觉规范（参照 WorkBuddy）

组件都在 `Packages/IronBowlKit/Sources/IronBowlKit/UI/DesignSystem.swift`，新页面只用 `DS*` 组件，不直接写颜色。

- **配色**：浅灰侧栏 `DS.sidebar` + 纯白内容区 `DS.canvas`；设置页灰底 `DS.groupBackground` 上放白卡。没有玻璃、渐变，只用 1px 细边框 `DS.border`。
- **按钮**：主按钮黑底白字 `.dsPrimary`（每页最多一个），次按钮白底细边 `.dsSecondary`，图标或轻按钮 `.dsGhost`，首页快捷标签 `.dsChip`。
- **控件**：开关为绿色 `DSToggle`；下拉为带边框的 `DSPicker`；输入框 `.textFieldStyle(.ds)`；数字用 `DSStepper`。
- **结构**：页面顶部 `DSPageHeader`（左标题、右操作）；设置用 `DSSection` + `DSRow`（左边粗体标题加灰色说明，右边控件）；指标用 `DSMetric`；提示用 `DSBanner`；卡片用 `DSCard`。
- **主窗口**：自绘侧栏（今天 + 各插件 + 「最近日志」 + 底部今日卡片 + 设置），首页「今天」包括居中问候、快捷标签、一句话记日志的输入框和小卡片。
- **设置窗口**：左侧搜索框加分组导航（「设置」和各插件分组），右侧是灰底白卡。
- **浮层**：菜单栏面板和提醒卡片同样是白卡、细边、黑色主按钮。

## 阶段一：框架 + 禅道日志

- **禅道**：`https://hwsz.chandao.com/`，企业版 biz4.1.3，PATH_INFO。账号密码登录拿 session，调网页 `.json` 接口给**任务记工时**；过期自动重登。
- **扫描**：根目录（默认 `/Users/yxhc/huanwei`）下 2 层 git 仓库，`--all` 分支，按作者邮箱过滤，按天汇总；可排除仓库。扫描方式可设：按需 / 按需+定时 N 分钟 / 仅手动。同一提交在多个文件夹出现时按哈希去重。
- **映射**：仓库 → 禅道项目，AI 推荐 + 人工确认，可多对一。
- **选任务**：AI 按提交内容在未关闭任务里挑；挑不出用上次任务；再不行记到全局「兜底任务」（默认名字含"杂项"），草稿标黄。
- **AI 提供者**：内置 `agy`、`codex`；各自可设路径（登录 shell 自动探测）、模型、思考深度、超时、额外参数、测试按钮；选一个默认，日志页可临时切换。只读运行。默认只发提交信息 + 文件名 + 增删行数，按项目可开"发送代码改动"。失败回退为拼接提交信息。
- **内容**：一个任务每天一条，中文 1–3 个业务要点；提示词可改。
- **工时**：默认 =（下班 − 上班 − 午休），按改动量分配，0.5h 取整，可手改；剩余默认 = 上次剩余 − 本次消耗（≥0），不自动完成任务。可手动加无提交的工作。
- **加班**：按钮弹框，默认 +2h，选任务，本地标记加班。
- **非工作日**：「非工作日也提醒」默认关；「非工作日工时默认算加班」默认开。
- **防重复**：生成前拉取禅道当天已有工时并计入；本地记录已提交；必须确认后提交；可补写最近 7 天。
- **提醒**：多个时间点；样式三选一（系统通知 / 右上角玻璃卡片常驻 / 屏幕中央玻璃弹框），每种可测试预览；按钮：去写日志 / N 分钟后提醒 / 今天不写。
- **工作日历**：工作日勾选、上下班与午休时间；节假日数据源可选（holiday-cn jsDelivr / holiday-cn GitHub / timor.tech / 仅手动），更新频率可选，手动标记优先。
- 侧边栏预留：万年历、飞书知识库、待办、周报日报（"即将推出"）。

## 阶段二：万年历插件 + 独立万年历

- 参照百度"今天"日历：顶栏（假期下拉 / 年下拉 / ‹月› / 今天）；周一开头，周末红字；格子显示 公历 + （节日 > 节气 > 农历日，初一也显示"初一"）；非本月灰；今天带「今」角标；底部卡片：农历日期 + 干支生肖 + 距离某日倒计时/已过天数。
- 额外：休/班角标、天气（数据源可选：Open-Meteo 默认免费 / 和风天气填 Key 和 API Host；城市用 Open-Meteo 地理编码搜索）、菜单栏日期 / 农历 / 天气、首页天气卡。
- 农历用系统中国历法；节气按太阳视黄经（Meeus 算法）计算，2026 年 24 节气与官方日期一致；节日含公历、农历（含除夕）、按星期算的（母亲节等）。
- 独立版「饭碗万年历」（`Apps/Calendar`，bundle id `com.taopaox.ironbowl.calendar`）：菜单栏显示日期 + 农历，点开是紧凑月历；可开大窗口和设置；与饭碗共用数据库、外观和字体设置。
- 暂缓：桌面小组件（WidgetKit 需要正式签名的开发者证书，当前是本地 ad-hoc 签名）；待办合并等「待办」插件做时一起做。
- 不做：宜忌黄历、头条、打赏、限行。
- 备忘/提醒/任务与工作台待办合并为一套数据。
- 用户另提供 `/Applications/万年历.app` 截图补充特有功能。
